# roadmapUI
This is a simple html + css form element that's focused on accessibility. 
It's a solution to one of [Roadmap.sh](https://roadmap.sh/projects/accessible-form-ui)'s projects. 

To run this, you can use this reliable tool called [GitHub & BitBucket HTML Preview] (https://htmlpreview.github.io/) 
or clone the repository using the following commands in your editor's terminal:
-  git clone https://github.com/I-M20/roadmapUI
-  cd roadmapUI (to open up the project folder)
then open the html
